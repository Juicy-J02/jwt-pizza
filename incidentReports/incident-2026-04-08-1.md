# Incident: 2026-04-08 10-39-30

## Summary

```md
Between the hour of 10:39 and 11:39 on 4/8/2026, all users encountered issues with ordering pizza from the pizza.jwtpizza-jgray10.click website. The event was triggered by a server error on the /api/order endpoint at 10:39. The endpoint error was invoked by a chaos trigger in the pizza-factory.cs329.click website.

A bug in this code caused all users to be unable to order any pizzas. Whenever the action was performed an error stating "Failed to fulfill order at factory" was given. The event was detected by my grafana chaos monitor which keeps track of all 500 level errors. The team started working on the event by viewing the message that was attached to the error within the network settings. Along with the message, a link was provided to end the chaos. Upon clicking this link, the endpoint was restored. This high level incident affected 100% of users.

There was further impact as noted by several instances of grafana on-call notifications being raised in relation to this incident.
```

## Detection

```md
This incident was detected when the chaos alert was triggered and Jackson Gray was paged.

Additional triggers were sent as Jackson was at work at this time . Once his shift was over he was able to acknowledge and respond to the error
```

## Impact

```md
For 1hr between 10:39 MST and 11:39 MST on 4/8/2026, pizzas were unable to be ordered from the pizza.jwtpizza-jgray10.click website by users of the application.

This incident affected all customers currently ordering from the website, who experienced an error stating "Failed to fulfill order at factory" whenever attempting to purchase a pizza.

Three On-call notifications were received within the timeframe.
```

## Root cause

```md
The chaos triggered by the pizza-factory.cs329.click website resulted in the /api/order endpoint to shut down. This resulted in returning 500 errors whenever an order was placed.
```

## Resolution

```md
The 500 error included both a message and link. After following the link the user was brought to a page which stated {"message":"Problem resolved. Pizza is back on the menu!"}. This resolved the issue as pizzas were then able to be ordered again.
```

## Prevention

```md
Other 500 errors seem to all stem from issues with the pizza factory.
```

## Action items

```md
1. Avoid pressing the chaos trigger in the pizza factory
2. Track large amounts of 500 errors to see if there is an issue within the factory
3. If chaos is triggered, user can follow provided link to end it
```
